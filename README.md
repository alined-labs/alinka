# Alinka

An accounts-payable agent for the Blinka challenge (HackRadar 30X). It reads invoices from email, PDF, image or chat, pays only what the company's rules allow, holds or escalates the rest with a reason, and keeps a log anyone can read.

**La IA lee, las reglas deciden, el registro explica.**
